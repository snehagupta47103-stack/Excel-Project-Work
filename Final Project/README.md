# 📅 Part B — Date & Time Functions

Date and time functions are used to analyze transaction timing and customer tenure.

### 1. TODAY

The `TODAY` function can be used to return the current date.

Example:

`=TODAY()`

### 2. NOW

The `NOW` function returns the current date and time.

Example:

`=NOW()`

### 3. DATEDIF

The `DATEDIF` function can be used to calculate the difference between dates, such as customer tenure.

Example:

`=DATEDIF(M2,TODAY(),"Y")`

This can be used to calculate the number of completed years since the customer relationship started.

### 4. EOMONTH

The `EOMONTH` function can be used to return the last date of a month.

Example:

`=EOMONTH(B2,0)`

This can support monthly transaction and reporting analysis.

---

# 🔎 Part C — FILTER Function

The `FILTER` function is used to return multiple records that meet a specified condition.

Example:

`=FILTER(A2:N251,K2:K251="North","No matching records")`

The FILTER function can be used for multi-value returns and dynamic transaction analysis.

### Purpose

- Retrieve transactions for a selected region.
- Return records matching a customer or product.
- Create dynamic analysis results.
- Support interactive reporting.
